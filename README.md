## ✨ Features

### 🎬 Smooth, efficient playback
- 🖥️ **Multiple displays, one decode.** A video is decoded once, however many displays show it, so they always stay on the same frame.
- 🔋 **Pauses when nobody can see it.** Decoding stops for a covered desktop, a fullscreen app, a locked screen, the screen saver, sleeping displays or another user in front.
- ⚡ **Smart optimization.** Suitable videos are copied as they are. The rest are converted to hardware-decodable HEVC, sized for your largest display. HDR and 10-bit are preserved.
- 🐢 **Per-wallpaper speed**, from 0.25× to 1×. Slower playback decodes proportionally fewer frames.

### 🎨 Make it yours
- 🌗 **Dimming and tint**, with an optional extra amount in dark mode.
- ✂️ **Loop editor.** Trim, crossfade the end into the beginning, and get automatic loop-point suggestions.
- 🪄 **Logo and watermark removal** with a before/after preview, applied once in the optimized copy, so it costs nothing during playback.
- 🌅 **Panorama.** Stretch one video across several displays, still decoded only once.

### 🗂️ Stay in control
- 🔁 **Playlists** that advance by interval, time of day or light/dark appearance.
- 📌 **Menu bar switcher** with thumbnails and a per-display submenu.
- 🤖 **Shortcuts actions and a Focus filter**: set a wallpaper, start or advance a playlist, pause and resume.
- 🪟 **A single main window** with Library, Displays, Playlists and Settings.
- 🌍 **English and Brazilian Portuguese.**
